AI-Assisted Table Analysis Workflow

A prototype for turning spreadsheet review into structured analysis, anomaly detection, and decision-ready summaries.

Workflow Demo

A short walkthrough of the interface from table input to analysis output, showing how the workflow is structured for review and interpretation.

Why This Matters

Spreadsheet analysis often lives in fragmented workflows: upload in one place, inspect anomalies in another, summarize findings manually, and then repackage insights for business users. This prototype explores how those steps can be unified into a single, more structured analysis flow.

Why It Fits My Fund Data Experience

My Morningstar work involved data verification, quality control, and coordination across data processes. This prototype extends that mindset into tool design: not just checking data manually, but organizing review logic into a repeatable workflow that supports faster and clearer analysis.

What The Demo Shows
Upload CSV/XLSX files and preview tabular structure directly in the interface.
Select numeric and grouping fields to shape the analysis workflow.
Generate anomaly-oriented demo data to simulate edge cases and review logic.
Produce summaries, anomaly signals, and chart-ready outputs in one flow.
